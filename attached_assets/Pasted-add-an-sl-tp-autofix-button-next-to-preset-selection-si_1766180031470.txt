Add the toast on Auto-Fix in client/src/components/EditTradeModal.tsx as follows.

1) Add a small helper (optional but clean)

Inside the component (near your other helpers), add:

  const toastPresetApplied = (points: number) => {
    toast({
      title: "TP/SL preset applied",
      description: `Set targets to ±${points} points from the ${priceLabel}.`,
    });
  };

2) Update the Auto-Fix button onClick to apply + toast

In the Quick presets block, change the Auto-Fix button to:

              <Button
                type="button"
                variant="outline"
                disabled={!referencePrice || referencePrice <= 0}
                className="border-emerald-500/25 bg-emerald-500/5 hover:bg-emerald-500/10"
                onClick={() => {
                  applyPreset(lastPresetPoints);
                  toastPresetApplied(lastPresetPoints);
                }}
                title={`Apply TP/SL using the current preset (±${lastPresetPoints} points)`}
              >
                Auto-Fix (±{lastPresetPoints})
              </Button>

3) Also toast when a preset is selected from the drop-up

In the dropdown item onSelect, update it to:

                      onSelect={() => {

                      }}
