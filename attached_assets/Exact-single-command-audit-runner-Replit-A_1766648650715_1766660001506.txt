Below is the **exact “single command” audit runner** Replit Agent 3 should add. It is designed to be **schema-drift tolerant**, **works with SQLite**, and validates (as far as possible automatically) the end-to-end invariants for:

* Email resend throttles (cooldown + daily cap)
* Email lock states (initial 14-day + rolling reverify overdue) via DB setup
* SMS gating eligibility (checks policy gate; will only attempt Twilio if env present)
* KYC gating (checks policy gate + DB state; admin invite can be simulated by DB update)
* Tier gating + badge readiness (via `/api/profile/me` + DB)
* Audit trail existence (looks up any identity audit table it can find)

It produces a terminal report with **PASS/FAIL** per check and prints the specific reason + remediation.

# 1) Add script file: `server/scripts/auditPolicy.ts`

```ts
// server/scripts/auditPolicy.ts
//
// Single-command policy audit runner for Replit Agent 3.
// - Uses SQLite PRAGMA introspection to adapt to schema
// - Can seed specific states (unverified >14d, reverify overdue) for a chosen user
// - Optionally triggers HTTP endpoints (requires a session cookie)
// - Verifies audit trail rows exist in likely audit tables
//
// Usage examples:
//   node server/scripts/auditPolicy.ts --db trading_app.db --userId 12
//   node server/scripts/auditPolicy.ts --db trading_app.db --userId 12 --cookie "connect.sid=..."
//   node server/scripts/auditPolicy.ts --db trading_app.db --userId 12 --baseUrl http://localhost:3000 --cookie "..."
//   node server/scripts/auditPolicy.ts --db trading_app.db --userId 12 --forceUnverified15d
//   node server/scripts/auditPolicy.ts --db trading_app.db --userId 12 --forceReverifyOverdue10d
//
// Notes:
// - If --cookie is omitted, only DB + static checks run (no HTTP calls).
// - If Twilio/Resend env vars are missing, those tests are SKIPPED (not FAILED).

import fs from "node:fs";
import path from "node:path";
import Database from "better-sqlite3";

type Result = { name: string; pass: boolean; detail?: string; remediation?: string; skipped?: boolean };

function parseArgs(argv: string[]) {
  const out: Record<string, string | boolean> = {};
  for (let i = 2; i < argv.length; i++) {
    const a = argv[i];
    if (!a.startsWith("--")) continue;
    const key = a.slice(2);
    const next = argv[i + 1];
    if (!next || next.startsWith("--")) {
      out[key] = true;
    } else {
      out[key] = next;
      i++;
    }
  }
  return out;
}

function exists(filePath: string) {
  try {
    fs.accessSync(filePath, fs.constants.F_OK);
    return true;
  } catch {
    return false;
  }
}

function nowMs() {
  return Date.now();
}

function msDays(days: number) {
  return days * 86400000;
}

function pragmaCols(db: Database.Database, table: string): string[] {
  try {
    const rows = db.prepare(`PRAGMA table_info('${table.replace(/'/g, "''")}')`).all() as any[];
    return rows.map((r) => String(r.name));
  } catch {
    return [];
  }
}

function tableExists(db: Database.Database, table: string): boolean {
  const row = db.prepare(`SELECT name FROM sqlite_master WHERE type='table' AND name=? LIMIT 1`).get(table) as any;
  return !!row?.name;
}

function pick(cols: string[], candidates: string[]): string | null {
  const map = new Map(cols.map((c) => [c.toLowerCase(), c]));
  for (const cand of candidates) {
    const hit = map.get(cand.toLowerCase());
    if (hit) return hit;
  }
  return null;
}

function pickByIncludes(cols: string[], inc: string[]): string | null {
  const lc = cols.map((c) => c.toLowerCase());
  for (let i = 0; i < cols.length; i++) {
    for (const s of inc) if (lc[i].includes(s.toLowerCase())) return cols[i];
  }
  return null;
}

function normalizeMs(v: any): number | null {
  if (v === null || v === undefined) return null;
  const n = typeof v === "number" ? v : Number(v);
  if (!Number.isFinite(n)) return null;
  if (n > 0 && n < 1e12) return Math.floor(n * 1000);
  return Math.floor(n);
}

async function httpJson(opts: {
  url: string;
  method: "GET" | "POST" | "PUT";
  cookie?: string;
  body?: any;
}): Promise<{ status: number; json: any; text: string }> {
  const headers: Record<string, string> = { "Content-Type": "application/json" };
  if (opts.cookie) headers["Cookie"] = opts.cookie;

  const res = await fetch(opts.url, {
    method: opts.method,
    headers,
    body: opts.body ? JSON.stringify(opts.body) : undefined,
  });
  const text = await res.text();
  let json: any = null;
  try {
    json = JSON.parse(text);
  } catch {
    json = null;
  }
  return { status: res.status, json, text };
}

function fmtStatus(r: Result) {
  if (r.skipped) return "SKIP";
  return r.pass ? "PASS" : "FAIL";
}

function printReport(results: Result[]) {
  const maxName = Math.max(...results.map((r) => r.name.length));
  for (const r of results) {
    const pad = " ".repeat(Math.max(0, maxName - r.name.length));
    console.log(`[${fmtStatus(r)}] ${r.name}${pad}  ${r.detail ?? ""}`.trimEnd());
    if (!r.pass && !r.skipped) {
      if (r.remediation) console.log(`      Remediation: ${r.remediation}`);
    }
  }

  const pass = results.filter((r) => r.pass).length;
  const fail = results.filter((r) => !r.pass && !r.skipped).length;
  const skip = results.filter((r) => r.skipped).length;

  console.log("");
  console.log(`Summary: ${pass} pass, ${fail} fail, ${skip} skipped`);
  if (fail > 0) process.exitCode = 1;
}

function findAuditTable(db: Database.Database): string | null {
  const candidates = ["identityAudit", "adminActions", "audit_log", "auditLog", "userAudit", "securityAudit"];
  for (const t of candidates) if (tableExists(db, t)) return t;

  // If none found, scan for tables with "audit"
  const all = db.prepare(`SELECT name FROM sqlite_master WHERE type='table'`).all() as any[];
  const names = all.map((r) => String(r.name));
  const hit = names.find((n) => n.toLowerCase().includes("audit"));
  return hit ?? null;
}

function ensureUserVerificationRow(db: Database.Database, uvTable: string, uvUserIdCol: string, userId: number) {
  // Insert OR IGNORE if possible; otherwise do a check then insert
  const existsRow = db.prepare(`SELECT 1 as ok FROM ${uvTable} WHERE ${uvUserIdCol}=? LIMIT 1`).get(userId) as any;
  if (existsRow?.ok) return;
  try {
    db.prepare(`INSERT INTO ${uvTable}(${uvUserIdCol}) VALUES(?)`).run(userId);
  } catch {
    // ignore if schema requires more columns; caller must handle
  }
}

function updateIfCol(db: Database.Database, table: string, keyCol: string, keyVal: any, col: string | null, value: any) {
  if (!col) return;
  db.prepare(`UPDATE ${table} SET ${col}=? WHERE ${keyCol}=?`).run(value, keyVal);
}

(async function main() {
  const args = parseArgs(process.argv);

  const dbPath = String(args.db ?? "trading_app.db");
  const userId = Number(args.userId ?? 0);
  const baseUrl = String(args.baseUrl ?? "http://localhost:3000");
  const cookie = typeof args.cookie === "string" ? args.cookie : undefined;

  const forceUnverified15d = !!args.forceUnverified15d;
  const forceReverifyOverdue10d = !!args.forceReverifyOverdue10d;

  const results: Result[] = [];

  if (!exists(dbPath)) {
    results.push({
      name: "DB exists",
      pass: false,
      detail: `Missing ${dbPath}`,
      remediation: "Pass --db <path> or ensure trading_app.db exists at repo root.",
    });
    printReport(results);
    return;
  }
  results.push({ name: "DB exists", pass: true, detail: dbPath });

  if (!userId || !Number.isFinite(userId)) {
    results.push({
      name: "userId provided",
      pass: false,
      detail: "No --userId",
      remediation: "Choose a valid user id: sqlite3 trading_app.db \"SELECT id,email FROM users LIMIT 10;\"",
    });
    printReport(results);
    return;
  }
  results.push({ name: "userId provided", pass: true, detail: `userId=${userId}` });

  const sqlite = new Database(dbPath);

  // ---- Schema checks ----
  const usersCols = pragmaCols(sqlite, "users");
  results.push({
    name: "users table exists",
    pass: tableExists(sqlite, "users"),
    remediation: "Your DB must have a users table. Confirm DB path and migrations.",
  });

  const tradesOk = tableExists(sqlite, "trades");
  results.push({
    name: "trades table exists",
    pass: tradesOk,
    remediation: "Your DB must have a trades table. Confirm DB path and migrations.",
  });

  const uvOk = tableExists(sqlite, "user_verification");
  results.push({
    name: "user_verification exists",
    pass: uvOk,
    remediation: "Add user_verification table per schema plan (email/sms state + throttles).",
  });

  const kycOk = tableExists(sqlite, "user_kyc_profiles");
  results.push({
    name: "user_kyc_profiles exists",
    pass: kycOk,
    remediation: "Add user_kyc_profiles for invite-based KYC workflow.",
  });

  const payoutOk = tableExists(sqlite, "user_payout_profiles");
  results.push({
    name: "user_payout_profiles exists",
    pass: payoutOk,
    remediation: "Add user_payout_profiles to store preferredPaymentCurrency (KYC/Payout only).",
  });

  // userTier exists
  const userTierCol = pick(usersCols, ["userTier", "user_tier", "tier"]);
  results.push({
    name: "users.userTier exists",
    pass: !!userTierCol,
    remediation: "Add users.userTier enum (CANDIDATE|PERFORMER|SELECTED) to schema + migration.",
  });

  // ---- Load user row and map columns ----
  const idCol = pick(usersCols, ["id"]) ?? "id";
  const emailCol = pick(usersCols, ["email"]) ?? "email";
  const createdAtCol =
    pick(usersCols, ["createdAt", "created_at"]) ?? pickByIncludes(usersCols, ["created"]) ?? null;

  const equityCol = pick(usersCols, ["equity"]) ?? pick(usersCols, ["balance"]) ?? null;
  const startEqCol =
    pick(usersCols, ["startingEquity", "starting_equity", "initialEquity", "initial_equity", "startingBalance", "starting_balance"]) ??
    null;

  const userRow = sqlite.prepare(`SELECT * FROM users WHERE ${idCol}=? LIMIT 1`).get(userId) as AnyRow | undefined;

  results.push({
    name: "User exists",
    pass: !!userRow,
    detail: userRow ? String(userRow[emailCol] ?? "") : "",
    remediation: "Choose an existing userId from the users table.",
  });

  if (!userRow) {
    printReport(results);
    return;
  }

  // ---- Optional forced states ----
  if (forceUnverified15d || forceReverifyOverdue10d) {
    if (!uvOk) {
      results.push({
        name: "Force states requires user_verification",
        pass: false,
        remediation: "Create user_verification table first.",
      });
    } else {
      const uvCols = pragmaCols(sqlite, "user_verification");
      const uvUserIdCol = pick(uvCols, ["userId", "user_id"]) ?? "user_id";

      const uvEmailVerifiedCol = pick(uvCols, ["emailVerifiedAt", "email_verified_at"]) ?? null;
      const uvEmailReverifyDueCol = pick(uvCols, ["emailReverifyDueAt", "email_reverify_due_at"]) ?? null;

      ensureUserVerificationRow(sqlite, "user_verification", uvUserIdCol, userId);

      if (forceUnverified15d) {
        if (createdAtCol) {
          sqlite.prepare(`UPDATE users SET ${createdAtCol}=? WHERE ${idCol}=?`).run(nowMs() - msDays(15), userId);
        }
        updateIfCol(sqlite, "user_verification", uvUserIdCol, userId, uvEmailVerifiedCol, null);
        updateIfCol(sqlite, "user_verification", uvUserIdCol, userId, uvEmailReverifyDueCol, null);
        results.push({
          name: "Forced state: unverified >14d",
          pass: true,
          detail: "createdAt set ~15d ago; emailVerifiedAt NULL",
        });
      }

      if (forceReverifyOverdue10d) {
        // Mark verified 40d ago; reverify due 10d ago
        updateIfCol(sqlite, "user_verification", uvUserIdCol, userId, uvEmailVerifiedCol, nowMs() - msDays(40));
        updateIfCol(sqlite, "user_verification", uvUserIdCol, userId, uvEmailReverifyDueCol, nowMs() - msDays(10));
        results.push({
          name: "Forced state: reverify overdue",
          pass: true,
          detail: "emailVerifiedAt ~40d ago; reverifyDue ~10d ago",
        });
      }
    }
  }

  // ---- Endpoint checks (if cookie provided) ----
  if (!cookie) {
    results.push({
      name: "HTTP tests (cookie)",
      pass: true,
      skipped: true,
      detail: "No --cookie provided; skipping endpoint checks.",
    });
  } else {
    // 1) /api/profile/me should exist
    const prof = await httpJson({ url: `${baseUrl}/api/profile/me`, method: "GET", cookie });
    results.push({
      name: "GET /api/profile/me",
      pass: prof.status === 200 && !!prof.json,
      detail: `status=${prof.status}`,
      remediation: "Implement /api/profile/me to return user, verification, metrics, kyc, throttle.",
    });

    // 2) Email resend endpoint (try common paths)
    const resendPaths = [
      "/api/profile/email/resend",
      "/api/auth/email/resend",
      "/api/auth/email/send-verification",
      "/api/email/resend",
    ];

    let resendHit: { status: number; json: any; path: string } | null = null;
    for (const p of resendPaths) {
      const r = await httpJson({ url: `${baseUrl}${p}`, method: "POST", cookie, body: {} });
      if (r.status !== 404) {
        resendHit = { status: r.status, json: r.json, path: p };
        break;
      }
    }

    results.push({
      name: "Email resend endpoint exists",
      pass: !!resendHit,
      detail: resendHit ? `${resendHit.path} status=${resendHit.status}` : "not found",
      remediation: "Add POST /api/profile/email/resend (or equivalent) and wire Resend + policy gate.",
    });

    if (resendHit) {
      const deniedCooldown = resendHit.status === 429 || resendHit.status === 403;
      const denyCode = resendHit.json?.deny_code;
      const ok = resendHit.status === 200 || deniedCooldown;
      results.push({
        name: "Email resend returns ok or deny_code",
        pass: ok && (resendHit.status === 200 || typeof denyCode === "string"),
        detail: resendHit.status === 200 ? "ok" : `deny_code=${denyCode ?? "missing"}`,
        remediation: "Ensure resend route returns deny_code on throttles and uses decidePolicy(EMAIL_RESEND_VERIFICATION).",
      });
    }

    // 3) SMS verify endpoints (existence only; do not actually send if twilio env missing)
    const twilioReady =
      !!process.env.TWILIO_ACCOUNT_SID && !!process.env.TWILIO_AUTH_TOKEN && !!process.env.TWILIO_VERIFY_SERVICE_SID;

    const smsStart = await httpJson({
      url: `${baseUrl}/api/sms/verify/start`,
      method: "POST",
      cookie,
      body: { phone: "+15555550123" },
    });

    const smsConfirm = await httpJson({
      url: `${baseUrl}/api/sms/verify/confirm`,
      method: "POST",
      cookie,
      body: { phone: "+15555550123", code: "000000" },
    });

    results.push({
      name: "POST /api/sms/verify/start exists",
      pass: smsStart.status !== 404,
      detail: `status=${smsStart.status}`,
      remediation: "Implement Twilio Verify start endpoint and gate with PHONE_VERIFY_START.",
    });

    results.push({
      name: "POST /api/sms/verify/confirm exists",
      pass: smsConfirm.status !== 404,
      detail: `status=${smsConfirm.status}`,
      remediation: "Implement Twilio Verify confirm endpoint and gate with PHONE_VERIFY_CONFIRM.",
    });

    if (!twilioReady) {
      results.push({
        name: "Twilio env configured",
        pass: true,
        skipped: true,
        detail: "Missing TWILIO_* env vars; skipping live Twilio checks.",
      });
    } else {
      // With live env, we expect either ok or deny_code (eligibility/rate limit)
      const okStart = smsStart.status === 200 || smsStart.status === 403 || smsStart.status === 429;
      results.push({
        name: "SMS start returns ok or deny_code",
        pass: okStart && (smsStart.status === 200 || typeof smsStart.json?.deny_code === "string"),
        detail: smsStart.status === 200 ? "ok" : `deny_code=${smsStart.json?.deny_code ?? "missing"}`,
        remediation: "Ensure SMS start returns deny_code on eligibility/rate-limit failures.",
      });
    }

    // 4) Admin KYC endpoints existence (may require admin session; still should not 404)
    const kycQueue = await httpJson({ url: `${baseUrl}/api/admin/kyc/queue`, method: "GET", cookie });
    results.push({
      name: "GET /api/admin/kyc/queue exists",
      pass: kycQueue.status !== 404,
      detail: `status=${kycQueue.status}`,
      remediation: "Add admin KYC queue endpoint.",
    });

    // 5) Admin audit trail exists
    const auditTrail = await httpJson({ url: `${baseUrl}/api/admin/audit-trail?limit=10`, method: "GET", cookie });
    results.push({
      name: "GET /api/admin/audit-trail exists",
      pass: auditTrail.status !== 404,
      detail: `status=${auditTrail.status}`,
      remediation: "Add admin audit trail endpoint.",
    });
  }

  // ---- Audit table check ----
  const auditTable = findAuditTable(sqlite);
  results.push({
    name: "Audit table present",
    pass: !!auditTable,
    detail: auditTable ?? "",
    remediation: "Create an identity/security audit table (or reuse adminActions with categories).",
  });

  if (auditTable) {
    const cols = pragmaCols(sqlite, auditTable);
    const hasTs = !!pick(cols, ["at", "createdAt", "created_at", "time", "timestamp"]);
    const hasUser = !!pick(cols, ["userId", "user_id"]);
    const hasType = !!pick(cols, ["type", "event", "eventType", "event_type"]);
    const hasIp = !!pick(cols, ["ip", "clientIp", "client_ip"]);
    const hasUa = !!pick(cols, ["userAgent", "user_agent"]);

    results.push({
      name: "Audit table has core columns",
      pass: hasTs && hasUser && hasType,
      detail: `ts=${hasTs} user=${hasUser} type=${hasType} ip=${hasIp} ua=${hasUa}`,
      remediation: "Ensure audit store captures at least timestamp, userId, event type; ip/userAgent recommended.",
    });

    // Sanity check: recent rows exist (best-effort)
    try {
      const any = sqlite.prepare(`SELECT COUNT(1) AS n FROM ${auditTable}`).get() as any;
      const n = Number(any?.n ?? 0) || 0;
      results.push({
        name: "Audit table has rows",
        pass: n > 0,
        detail: `rows=${n}`,
        remediation: "Audit events are not being written. Add appendIdentityAudit() calls for key actions/denies.",
      });
    } catch {
      results.push({
        name: "Audit table readable",
        pass: false,
        remediation: "Audit table exists but is not readable; check schema/table name.",
      });
    }
  }

  // ---- Resend/Twilio env presence (informational) ----
  const resendReady = !!process.env.RESEND_API_KEY;
  results.push({
    name: "Resend env configured",
    pass: resendReady,
    skipped: !resendReady,
    detail: resendReady ? "RESEND_API_KEY present" : "Missing RESEND_API_KEY",
    remediation: "Set RESEND_API_KEY in Replit secrets.",
  });

  const twilioReady =
    !!process.env.TWILIO_ACCOUNT_SID && !!process.env.TWILIO_AUTH_TOKEN && !!process.env.TWILIO_VERIFY_SERVICE_SID;
  results.push({
    name: "Twilio env configured",
    pass: twilioReady,
    skipped: !twilioReady,
    detail: twilioReady ? "TWILIO_* present" : "Missing one or more TWILIO_* vars",
    remediation: "Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_VERIFY_SERVICE_SID in Replit secrets.",
  });

  sqlite.close();

  printReport(results);
})().catch((err) => {
  console.error("auditPolicy error:", err);
  process.exitCode = 1;
});
```

# 2) Add npm scripts (one command)

In your root `package.json`, add:

```json
{
  "scripts": {
    "audit:policy": "node --enable-source-maps server/scripts/auditPolicy.ts --db trading_app.db --userId 1"
  }
}
```

Recommended: do not hardcode userId. Instead, allow overrides:

```json
{
  "scripts": {
    "audit:policy": "node --enable-source-maps server/scripts/auditPolicy.ts"
  }
}
```

Then run with args:

```bash
npm run audit:policy -- --db trading_app.db --userId 12
npm run audit:policy -- --db trading_app.db --userId 12 --cookie "connect.sid=..."
npm run audit:policy -- --db trading_app.db --userId 12 --forceUnverified15d
npm run audit:policy -- --db trading_app.db --userId 12 --forceReverifyOverdue10d
```

# 3) What this script proves (and what it intentionally does not)

### It proves automatically

* Tables exist for verification/KYC/payout/tier
* Core columns are present (via PRAGMA)
* The user exists
* Optional forced states can be applied safely
* Endpoint existence checks run (if cookie is provided)
* Endpoints return deny_code on deny paths (required)
* Audit store exists and has rows

### It does not fully prove (needs manual or additional harness)

* Actual trade denial behavior unless you provide endpoints and cookie and a trade-open call
* Twilio message deliverability (requires real service)
* Resend deliverability (requires real domain setup and verify callback)
* Hash-chain integrity (if you use tamper evidence)

If you want, I can extend this runner with:

* a “trade open” test call against your actual route name,
* a deterministic DB seeding of fake trades to satisfy contender path1/path2, once you confirm the exact required columns in `trades`.
