1) What hedge funds / trading houses actually screen for in a trader (and why)
Most institutional allocators and professional desks don’t screen purely on PnL. They screen on repeatability, risk governance, capacity, and style-fit.

1.1 Industry “shape” of due diligence
Institutional due diligence questionnaires (DDQs) are standardized around: strategy, markets traded, risk management, leverage, liquidity risk, performance/valuation, operations. AIMA DDQs are explicitly positioned as an investor due-diligence standard/template. 

1.2 What that means for your platform’s “Trader Scouting” filters
Below are the filters/columns hedge funds/desks actually care about, expressed as screenable metrics you can compute from trade + equity curves + instrument metadata.

A) Return quality (risk-adjusted, not raw)
Sharpe / Sortino (needs periodic returns series, not just trade list)

Max drawdown, drawdown duration, and recovery time (peak-to-trough behavior)

Volatility / downside deviation

Calmar ratio (CAGR / MaxDD) for longer windows
Why: investors compare same return with different risk profiles; Sharpe + drawdowns are core comparators. CME Group explicitly teaches evaluating managers by risk taken, Sharpe, drawdowns rather than return alone. 

B) Edge diagnostics (trade expectancy, efficiency)
Profit Factor (gross profit / gross loss)

Expectancy (avg R or avg $ per trade after losses)

Average win / average loss, payoff ratio

MAE/MFE (max adverse/favorable excursion — requires intra-trade prices or bar sampling)
Prop and evaluation environments emphasize PF/expectancy/drawdown more than win rate alone. 

C) Style & time-horizon fit
Holding time distribution (avg/median, P10/P90, min/max)

Trade frequency, turnover, “burstiness”

Session bias (Asia/Europe/US), day-of-week patterns

Overnight/weekend exposure
This matters because some desks want intraday scalpers, others want swing, others want multi-day.

D) Market / instrument specialization
Asset class mix: FX vs Stocks vs ETFs vs Crypto vs Commodities vs Indices vs Bonds

Concentration: top symbol %, top 5 symbols %

Region/country/exchange exposure (for equities)
Fit: a fund might be explicitly seeking “equities only, US listed, low overnight”.

E) Risk governance / discipline signals
Stop-loss usage %, take-profit usage %

Position sizing stability (variance of notional risk)

Max leverage used; average leverage used

Risk-per-trade (as % equity), worst loss day/week
Risk discipline is part of formal “risk management” evaluation.

function clampNum(v: string, fallback: number): number {
  const n = Number(v);
  return Number.isFinite(n) ? n : fallback;
}

function formatPct01(v: number | null | undefined): string {
  if (v === null || v === undefined) return "—";
  return `${(v * 100).toFixed(1)}%`;
}

function formatMoney(v: number | null | undefined): string {
  if (v === null || v === undefined) return "—";
  const sign = v < 0 ? "-" : "";
  const abs = Math.abs(v);
  if (abs >= 1_000_000) return `${sign}$${(abs / 1_000_000).toFixed(2)}M`;
  if (abs >= 1_000) return `${sign}$${(abs / 1_000).toFixed(2)}K`;
  return `${sign}$${abs.toFixed(2)}`;
}

function formatDuration(sec: number | null | undefined): string {
  if (sec === null || sec === undefined) return "—";
  if (!Number.isFinite(sec)) return "—";
  const s = Math.max(0, Math.floor(sec));
  const mins = Math.floor(s / 60);
  const hrs = Math.floor(mins / 60);
  const days = Math.floor(hrs / 24);
  const remHrs = hrs % 24;
  const remMins = mins % 60;
  if (days > 0) return `${days}d ${remHrs}h`;
  if (hrs > 0) return `${hrs}h ${remMins}m`;
  return `${remMins}m`;
}

function mixToBadges(mix?: Record<string, number> | null): { label: string; value: number }[] {
  if (!mix) return [];
  const entries = Object.entries(mix)
    .filter(([, v]) => Number.isFinite(v) && v > 0)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 4);
  return entries.map(([k, v]) => ({ label: k, value: v }));
}
