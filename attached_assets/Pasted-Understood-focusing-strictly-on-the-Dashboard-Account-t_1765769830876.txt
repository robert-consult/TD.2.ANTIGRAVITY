## Floating P/L formula/logic check (Account tab)

### What you have now

* `server/recalcAccount.ts` computes:

  * `floatingProfit = Σ unrealizedPnl(openTrades, currentPrice)`
  * `equity = balance + floatingProfit`
* `/api/account/summary` returns:

  * `floatingPnl = equity - balance`

That structure is correct (MetaTrader-style), **provided currentPrice is valid**.

### The main operational risk

If the quotes table is missing, stale, or symbol-mismatched, `recalcAccount.ts` explicitly falls back to:

```ts
priceCache.set(symbol, trade.openPrice)
```

which forces **unrealized P/L = 0** and therefore **equity == balance** even with open positions.

If you’re seeing that symptom, the bug is not the formula — it’s **quote availability/consistency** at recalc time.
