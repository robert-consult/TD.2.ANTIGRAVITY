### c. **Backend Computation Logic**

* Cron job or on-demand aggregation using SQL or Prisma/Drizzle:

```sql
SELECT
  instrument,
  COUNT(*) AS trades,
  AVG(profit) AS avg_profit,
  AVG(EXTRACT(EPOCH FROM (exit_time - entry_time)) / 60) AS avg_hold_minutes,
  SUM(CASE WHEN profit > 0 THEN 1 ELSE 0 END)::float / COUNT(*) AS win_rate,
  direction
FROM trades
WHERE user_id = $1
GROUP BY instrument, direction
ORDER BY avg_profit DESC;
```
