Below is a **drop-in “View as Trader” (admin impersonation)** architecture + file structure + implementation code that is consistent with your existing AdminDashboard patterns (React Query + axios + admin user-management actions/mini-tabs) and adds the missing hedge-fund-grade controls: **explicit actor vs effective user**, **sessionized audit trail**, **clear UI banner**, and **hard admin-only enforcement**. 

---

## Target behavior and pass criteria

Your “View as Trader” must satisfy these invariants (the “tests” you care about operationally):

1. **Admin-only:** non-admins cannot start/stop impersonation (403).
2. **Effective identity switch:** once started, the platform behaves exactly as if logged in as the trader (effective user = trader).
3. **Actor preserved:** every write (trade open/close, deposit/withdraw, settings change, etc.) stores:

   * `effectiveUserId` (the trader) and
   * `actorUserId` (the admin who impersonated).
4. **Auditable session:** impersonation has a session row with start/stop timestamps, IP, user-agent; actions can reference `impersonationSessionId`.
5. **Obvious UI state:** global banner “Viewing as Trader X (Admin Y)” + “Stop impersonation”.
6. **Risk gates still apply:** if the trader is frozen/disabled, the impersonated session should see the same blocks the trader would see.

---

## Architecture (clean separation: Actor vs Effective User)

### Token / session claims

Use a single auth context derived from either:

* **httpOnly cookie token** (recommended), or
* `Authorization: Bearer <token>` header.

Token claims:

* `sub` = real logged-in user (admin)
* `role` = `ADMIN`
* `actAs` = trader userId (optional; when present → impersonating)
* `impSessionId` = UUID of the impersonation session (optional)

### Request context (every request)

Middleware derives:

```ts
actorUserId      = token.sub
effectiveUserId  = token.actAs ?? token.sub
isImpersonating  = !!token.actAs
impSessionId     = token.impSessionId ?? null
```

Then **all business logic uses `effectiveUserId`** to fetch balances/positions/limits, but **all writes also store `actorUserId`** for audit.

## `/backend/src/auth/jwt.ts`

```ts
import jwt from "jsonwebtoken";
import type { AuthClaims } from "./types";

const JWT_SECRET = process.env.JWT_SECRET || "dev-secret-change-me";
const DEFAULT_TTL_SEC = Number(process.env.JWT_TTL_SEC || 60 * 60 * 6); // 6h

export function signClaims(claims: AuthClaims, ttlSec: number = DEFAULT_TTL_SEC) {
  return jwt.sign(claims, JWT_SECRET, { expiresIn: ttlSec });
}

export function verifyToken(token: string): AuthClaims {
  return jwt.verify(token, JWT_SECRET) as AuthClaims;
}
```

## `/backend/src/middleware/authContext.ts`

```ts
import type { Request, Response, NextFunction } from "express";
import { verifyToken } from "../auth/jwt";
import type { AuthContext, AuthClaims } from "../auth/types";

declare global {
  namespace Express {
    interface Request {
      auth?: AuthContext;
      authClaims?: AuthClaims;
    }
  }
}

function extractToken(req: Request): string | null {
  // Prefer httpOnly cookie (recommended)
  const cookieName = process.env.AUTH_COOKIE_NAME || "auth_token";
  const fromCookie = (req as any).cookies?.[cookieName];
  if (fromCookie) return fromCookie;

  // Fallback: Authorization header
  const h = req.headers.authorization;
  if (h && h.toLowerCase().startsWith("bearer ")) return h.slice(7).trim();

  return null;
}

export function authContext(req: Request, res: Response, next: NextFunction) {
  const token = extractToken(req);
  if (!token) return res.status(401).json({ message: "Unauthorized" });

  try {
    const claims = verifyToken(token);
    req.authClaims = claims;

    const actorUserId = claims.sub;
    const effectiveUserId = claims.actAs ?? claims.sub;

    req.auth = {
      actorUserId,
      role: claims.role,
      effectiveUserId,
      isImpersonating: typeof claims.actAs === "number",
      impersonatedUserId: typeof claims.actAs === "number" ? claims.actAs : null,
      impersonationSessionId: claims.impSessionId ?? null,
    };

    return next();
  } catch {
    return res.status(401).json({ message: "Unauthorized" });
  }
}
```

## `/backend/src/middleware/requireAdmin.ts`

```ts
import type { Request, Response, NextFunction } from "express";

export function requireAdmin(req: Request, res: Response, next: NextFunction) {
  if (!req.auth) return res.status(401).json({ message: "Unauthorized" });
  if (req.auth.role !== "ADMIN") return res.status(403).json({ message: "Forbidden" });
  return next();
}
```

function setAuthCookie(res: Response, token: string) {
  const cookieName = process.env.AUTH_COOKIE_NAME || "auth_token";
  const secure = process.env.NODE_ENV === "production";
  res.cookie(cookieName, token, {

export function mountAdminImpersonationRoutes(router: Router) {
  // Start impersonation
  router.post(
    "/api/admin/impersonation/start",
    authContext,
    requireAdmin,
    async (req: Request, res: Response) => {
      const { traderUserId } = req.body as { traderUserId: number };
      if (!traderUserId || typeof traderUserId !== "number") {
        return res.status(400).json({ message: "traderUserId is required" });
      }

      const adminId = req.auth!.actorUserId;

      const trader = await getUserById(traderUserId);
      if (!trader) return res.status(404).json({ message: "Trader not found" });
      if (trader.isAdmin) return res.status(400).json({ message: "Cannot impersonate another admin" });

      const session = await createImpersonationSession({
        adminUserId: adminId,
        traderUserId,
        ip: (req.headers["x-forwarded-for"] as string)?.split(",")[0]?.trim() || req.ip || null,
        userAgent: req.headers["user-agent"] || null,

      const newToken = signClaims({
        sub: adminId,
        role: "ADMIN",
        actAs: traderUserId,
        impSessionId: session.id,
      });

      // cookie-mode (preferred)
      setAuthCookie(res, newToken);

      await auditEvent({
        type: "IMPERSONATION_START",
        actorUserId: adminId,
        effectiveUserId: traderUserId,
        impersonationSessionId: session.id,
        metadata: { traderUserId },
      });

      return res.json({
        ok: true,
        impersonationSessionId: session.id,
        trader: { id: trader.id, email: trader.email, username: trader.username },
      });
    }
  );

  // Stop impersonation
  router.post(
    "/api/admin/impersonation/stop",
    authContext,
    requireAdmin,
    async (req: Request, res: Response) => {
      const adminId = req.auth!.actorUserId;
      const sessionId = req.auth!.impersonationSessionId;

      if (sessionId) await endImpersonationSession(sessionId);

      const newToken = signClaims({
        sub: adminId,
        role: "ADMIN",
        // no actAs
      });

      setAuthCookie(res, newToken);

      await auditEvent({
        type: "IMPERSONATION_STOP",
        actorUserId: adminId,
        effectiveUserId: adminId,
        impersonationSessionId: sessionId,
      });

      return res.json({ ok: true });
    }
  );
}

## Trade engine wiring (the crucial part)

Wherever you currently do “who is the user” in trading routes/services, switch to:

```ts
const { actorUserId, effectiveUserId, impersonationSessionId } = req.auth!;
```

Then:

* fetch positions/balance/settings using `effectiveUserId`
* insert trade rows with `userId = effectiveUserId` **and** `actorUserId = actorUserId` (and `impersonationSessionId` if you add it)

## Implementation notes (the tweaks that prevent failures)

* **Never “overwrite identity” in DB reads/writes implicitly.** Always compute `effectiveUserId` once in middleware and pass explicitly.
* **Prohibit admin→admin impersonation** (prevents privilege confusion and circular blame).
* **Short TTL tokens** for impersonation if you want tighter control (e.g., 30 minutes).
* **Stop impersonation on logout** by clearing cookie; keep it deterministic.
* **Audit on both boundaries** (start + stop), and include `impersonationSessionId` in downstream audit/trade rows.
