# 1) Revised enforcement policy

**Precedence hierarchy**

| Level | Source               | Purpose                   | Example                               |
| ----- | -------------------- | ------------------------- | ------------------------------------- |
| 1     | `user_settings`      | Trader-specific overrides | Exceptional trader allowed 100 lots   |
| 2     | `global_settings`    | Platform default limits   | Default 50 lots cap                   |
| 3     | Hard defaults (code) | Safe fallback if DB empty | 5 trades / 3 per instrument / 50 lots |

If a user setting exists, it **replaces** (not capped by) the global default.

# 2) Risk middleware (`server/risk.ts`)

Replace your entire `getEffectiveLimits()` with this:

```ts
async function getEffectiveLimits(userId: number) {
  const gs =
    (await db.query.globalSettings.findFirst({
      where: eq(globalSettings.id, 1),
    })) ?? null;

  const us = (await storage.getUserSettingsById(userId)) ?? null;

  const effective = {
    maxTradesPerUser:
      us?.maxConcurrent ??
      Number(gs?.maxTradesPerUser ?? DEFAULTS.maxTradesPerUser),
    maxTradesPerInstrument:
      us?.maxConcurrentPerInstrument ??
      Number(gs?.maxTradesPerInstrument ?? DEFAULTS.maxTradesPerInstrument),
    maxConcurrentLots:
      us?.maxConcurrentLots ??
      Number(gs?.maxConcurrentLots ?? DEFAULTS.maxConcurrentLots),
    dailyLossLimitPct:
      us?.dailyLossLimitPct ??
      Number(gs?.dailyLossLimitPct ?? DEFAULTS.dailyLossLimitPct),
    lifetimeLossLimitPct:
      us?.lifetimeLossLimitPct ??
      Number(gs?.lifetimeLossLimitPct ?? DEFAULTS.lifetimeLossLimitPct),
  };

  return effective;
}
```

Now, per-user limits **override** global limits rather than being capped.
