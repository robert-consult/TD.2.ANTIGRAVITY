* Email validation (initial + resend throttles)
* Rolling email revalidation (30-day due + overdue lock)
* SMS validation (Twilio Verify) with contender-only gating
* KYC (invite-based; Selected-tier gating)

* Admin mini-tabs + backend endpoints

This assumes your DB is `trading_app.db` (per prior context). If different, replace accordingly.
