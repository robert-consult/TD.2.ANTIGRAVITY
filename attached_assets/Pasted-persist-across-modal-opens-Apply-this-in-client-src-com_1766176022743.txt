Below is a per-symbol persistence implementation for your TP/SL preset dropdown in client/src/components/EditTradeModal.tsx, using localStorage keys that vary by symbol (or symbolId).

It is designed to avoid the common bug where the “save” effect overwrites the newly selected symbol’s stored preset before the “load” effect applies it.

1) Update React imports

At the top of EditTradeModal.tsx, ensure you import useMemo and useRef:

(If you already import useEffect/useState, just expand the list.)

2) Replace your current persistence logic with per-symbol key + guarded hydrate/save

Inside the component body, replace the prior global-key state/effects with the following block.

Add this block near the top of the component (after you have access to trade)
  const AUTO_FIX_PRESETS = [10, 50, 100, 150, 200] as const;

  const getSymbolStorageKey = (t: any) => {
    // Prefer stable numeric id if available; fallback to symbol string; otherwise global.
    const sid = t?.symbolId ?? t?.symbol_id;
    const sym = t?.symbol ?? t?.symbolName ?? t?.symbol_code;

    if (sid !== null && sid !== undefined && sid !== "") return `sid-${sid}`;
    if (sym) return `sym-${String(sym).toUpperCase()}`;
    return "global";
  };

  const presetStorageKey = useMemo(() => {
    const symbolKey = getSymbolStorageKey(trade);
    return `tc3al:lastPresetPoints:${symbolKey}`;
  }, [trade?.symbolId, trade?.symbol]);

  const skipNextSaveRef = useRef(false);

  const [lastPresetPoints, setLastPresetPoints] = useState<number>(10);

3) Load preset whenever the symbol changes (hydrate)

Add this useEffect (place it before the save effect):

  useEffect(() => {
    if (typeof window === "undefined") return;

    try {
      const raw = window.localStorage.getItem(presetStorageKey);
      const n = raw ? Number(raw) : 10;

      const allowed = [...AUTO_FIX_PRESETS] as unknown as number[];
      const value = allowed.includes(n) ? n : 10;

      // Prevent the subsequent save effect from writing the old value into the new symbol key.
      skipNextSaveRef.current = true;
      setLastPresetPoints(value);
    } catch {
      // If storage is blocked, fail gracefully.
      skipNextSaveRef.current = true;
      setLastPresetPoints(10);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [presetStorageKey]);

4) Save preset whenever it changes (per-symbol)

Add this useEffect (after the hydrate effect):

  useEffect(() => {
    if (typeof window === "undefined") return;

    // Skip the first save right after we hydrate from storage for a new symbol.
    if (skipNextSaveRef.current) {
      skipNextSaveRef.current = false;
      return;
    }

    try {
      window.localStorage.setItem(presetStorageKey, String(lastPresetPoints));
    } catch {
      // ignore storage failures
    }
  }, [lastPresetPoints, presetStorageKey]);
